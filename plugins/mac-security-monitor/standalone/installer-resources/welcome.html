__COMPANY__ — Mac Endpoint Security

MANDATORY IT-MANAGED SOFTWARE

This tool is provided by the __COMPANY__ IT Department to help keep company Mac computers — and the __COMPANY__ network — safe from unauthorized and hidden software.

What it does

Once installed, it runs quietly in the background and performs a periodic, read-only check of this Mac for unauthorized scripts or programs running in the background. It reviews startup items, background processes, and network listeners, and flags any software that is not part of __COMPANY__'s approved configuration.

Why you are seeing this

Under __COMPANY__'s Computer Usage & Endpoint Security Policy, this tool is a required component on all company-issued Mac computers. It protects you and the company from malware and unauthorized software that can hide inside the operating system and steal information or run without your knowledge.

Your privacy

The tool only reads the system configuration and running-process information needed to identify unauthorized background activity. It does not read your personal documents, email, messages, or browsing content, and it makes no changes to your Mac.
